## API documentation

Whenever an endpoint is created, updated, or deleted, update the OpenAPI docs in the same change.

- Docs are generated by swagger-jsdoc from `@openapi` JSDoc blocks placed directly above each route definition in `src/routes/*.ts` (see [src/config/swagger.ts](src/config/swagger.ts)).
- New route → add a `/** @openapi ... */` block (`tags`, `summary`, `security` for `authenticateJWT`-guarded routes, `requestBody`/`parameters`, `responses` referencing `ApiSuccessResponse`/`ApiErrorResponse` or a named schema).
- Changed route → update its existing block to match (params, body shape, auth, status codes).
- Removed route → delete its block too.
- If the route validates its body with a Joi schema, reuse it via `fromJoi(schema)` in `src/config/swagger.ts` (registered under `components.schemas`) instead of hand-writing the shape inline.
